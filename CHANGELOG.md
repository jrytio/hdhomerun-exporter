# Changelog

## 1.0.1

First public release.

- Exporter for SiliconDust HDHomeRun tuners over the device's TCP control protocol: signal strength and quality, reception error counters, bitrates, and which client is watching which channel.
- Grafana dashboard: what is playing now and how well it is received, viewing history per tuner, reception and throughput over time.
- Multi-arch container image (amd64 and arm64).
